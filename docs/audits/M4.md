## Gaps

- **G1 (M2 code, found here):** the `local-full` composition isn't hermetic. With `localOnly` and a local `modelLocation`, transformers.js still reads its default filesystem cache (`node_modules/@huggingface/transformers/.cache/`), which the pipeline's `embed` stage fills when it runs without a `cacheDir`. So an empty `modelDir` doesn't fail; the model loads from that cache. Nothing is downloaded, but the composition silently depends on files outside `modelDir`, and the slow test is environment-dependent (it passed at the M2/M3 audits, before that cache existed). Fix: when `modelLocation` is a local directory and `localOnly` is set, turn off the transformers.js filesystem/browser caches so only `modelDir` is consulted, and add a default-tier test on `configureEnv`.
